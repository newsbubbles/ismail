# The ismail kit

Every public voice and effect by family: what it is modeled on, how it did in front of the ear and which exam judged it, its range, its cost, and the gaps still open in each family.

Generated by `python -m ismail.kit` from showcase.json, presets.py, each voice's INFO and mimic profile, fx.py and the live engine, plus the hand-kept rows in `ismail/kit_tables.json`. Do not edit this page: change the sources or the tables and rerun. The same data is in [kit.json](kit.json); agents ask the `kit` op.

44 public voices, 11 with a known ear state; 28 effects.

## How to read it

- **type**: sampled: plays real recorded notes or hits (a sample set fetched on the person's word); measured: a code model (waveguide, modal, additive) whose numbers were fitted to recordings; mimic: a profile measured from a few real notes (partials, body, noise, room), rebuilt for any note; sprite: the built-in subtractive synth or drum synth, a designed patch with no real machine behind it; physical: a code model designed from the physics, not fitted to a recording; designed: a code voice designed by ear, not modeled on a recording.
- **ear**: passed: the listener could not tell it from the real thing, blind; usable: picked out, but "good enough"; failed: heard as not the instrument; pending: an exam is out or a round is under way, no verdict yet; untested: no ear test found. Each state names the exam or ledger row that judged it.
- **modeled on**: an instrument type, never a maker or a model name.
- **cost**: "not measured" until a render-time probe runs on a quiet machine; a voice's own note on its render time is quoted. A voice with a download plays samples fetched on the person's word (size given).
- A showcase voice (marked *) is one a first sketch reaches for.
