# Security

## Reporting a problem

Please report security problems privately, not in a public issue: on GitHub, open the repository's **Security** tab
and choose **Report a vulnerability**. Say what you found, how to reproduce it, and which version (`pip show ismail`,
or the commit). We aim to answer within a week, and we credit reporters in the changelog unless they ask us not to.

## Supported versions

The latest release on PyPI and the `main` branch get fixes. Older releases do not.

## Scope

ismail runs on the user's own computer. In scope: the engine and its ops (`ismail/`), the MCP server
(`ismail mcp`), the local pages ismail serves (the phone page, exam and feedback pages, the stage), the plugin
manifests, and the release workflow. Songs and projects people make with ismail are their own and out of scope.
